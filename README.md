# Ecos del Grimorio

Repositorio de documentación y avances del proyecto final de **Creación de Videojuegos** (10° D, UTP).
Aquí van los productos entregados, el arte del juego, el código C# y las evidencias de cada sprint.
El proyecto de Unity se trabaja por separado en la carpeta local `EcosDelGrimorio`.

- **Alumno:** Pérez Alcántara Alejandro
- **Docente:** José Francisco Espinosa Garita
- **Motor:** Unity 6 (6000.6.0f1), 2D URP
- **Lenguaje:** C# con Programación Orientada a Objetos y eventos (Action / UnityEvent), New Input System
- **Proceso:** Huddle (Preproducción, Producción, Postmortem)

## Sinopsis

Lira, una joven aprendiz de la Torre de Cristal, descubre que su grimorio de práctica contiene hechizos "sellados" de una hechicera desaparecida. Al usarlos libera ecos mágicos que empiezan a corromper la Torre. El jugador recorre la Torre nivel por nivel, aprende hechizos elementales y sus combos, y enfrenta a los guardianes de cada ala hasta restaurar el equilibrio del grimorio.

## Controles del prototipo

| Acción | Tecla |
|---|---|
| Moverse | A / D o flechas |
| Saltar | Espacio |
| Hechizos equipados | 1, 2, 3 |
| Repetir hechizo | J o clic izquierdo |
| Cambiar hechizo equipado | Q |
| Hablar / abrir cofre | E |
| Pausa | Esc (en pausa: L logros, R reiniciar, M menú) |
| Modo Archimaga (código secreto) | F, H, V, A, Intro |

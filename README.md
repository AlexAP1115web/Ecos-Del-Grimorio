# Ecos del Grimorio

Repositorio de documentación y avances del proyecto final de **Creación de Videojuegos** (10° D, UTP).
Aquí van los productos entregados, el arte del juego, el código C# y las evidencias de cada sprint.
El proyecto de Unity se trabaja por separado en la carpeta local `EcosDelGrimorio`.

## Jugar en línea

**https://alexap1115web.github.io/Ecos-Del-Grimorio/**

Se abre en la computadora (teclado o control) y en el celular (botones en pantalla). En el celular conviene ponerlo horizontal y, si se quiere, instalarlo como app desde el menú del navegador ("Agregar a la pantalla principal"). La versión para Windows (.exe) se entrega aparte en un .zip.

## Sinopsis

Lira, una joven aprendiz de la Torre de Cristal, descubre que su grimorio de práctica contiene hechizos "sellados" de una hechicera desaparecida. Al usarlos libera ecos mágicos que empiezan a corromper la Torre. El jugador recorre la Torre nivel por nivel, aprende hechizos elementales y sus combos, y enfrenta a los guardianes de cada ala hasta restaurar el equilibrio del grimorio.

## Controles

| Acción | Teclado | Control PS4 | Celular |
|---|---|---|---|
| Moverse | A / D | Stick izquierdo o cruceta | ◄ ► |
| Saltar | Espacio | X | Saltar |
| Agacharse | S | Stick o cruceta abajo | ▼ |
| Hechizos equipados | J, K, L (también 1, 2, 3) | Cuadrado, R1, L1 | 1, 2, 3 |
| Apuntar | W arriba (W + A/D en diagonal) o clic con el mouse | Stick derecho | ▲ (arriba) |
| Combo rápido | I (también C) | L2 | Combo |
| Cambiar hechizo equipado | U (también Q) | R2 | Cambiar |
| Esquive | Shift | Círculo | Esquivar |
| Planear (con Viento) | Mantener Espacio al caer | Mantener X al caer | Mantener Saltar al caer |
| Hablar / abrir cofre | E | Triángulo | Usar |
| Pausa | Esc o P | Options | II |
| Modo Archimaga (código secreto) | F, H, V, A, Intro | Mantener L1 + R1 y presionar Triángulo | Combo + Cambiar a la vez |
| Saltar nivel | Mantener N 1.5 s (o Pausa > Saltar nivel) | Mantener L3 + R3 1.5 s | Pausa > Saltar nivel |
